# 🌍 BEYOND NOMAD Atlas

> A curated cinematic travel discovery platform and atlas crafted for students, explorers, and late-night escape planners in Odisha.

BEYOND NOMAD Atlas transforms Odisha travel discovery into an immersive, emotionally-driven experience. Built with a premium dark aesthetic, real-time community interaction and personalized travel systems, the platform helps students discover realistic escapes beyond campus life.

## 🚀 Local Development

Clone the repository:

```bash
git clone https://github.com/sayakbhattasali/beyond-nomad-atlas.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

---

## 🔥 Firebase Setup

Create a `.env.local` file and add:

```env
NEXT_PUBLIC_FIREBASE_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
NEXT_PUBLIC_FIREBASE_APP_ID=

# AI Companion configuration (Optional / Local only)
GEMINI_API_KEY=
GROQ_API_KEY=
```

Enable:

* Google Authentication
* Cloud Firestore

inside Firebase Console.
